# 🚗 Car Price Prediction

A Machine Learning project that predicts the estimated price of a car based on its features. This project demonstrates the complete machine learning workflow, including data preprocessing, model training, and a simple web interface for making predictions.

---

## 📌 Project Overview

The goal of this project is to estimate the selling price of a car using machine learning. Users can enter car details through the web interface and receive a predicted price.

---

## ✨ Features

- Predicts car prices using a trained ML model
- User-friendly web interface
- Data preprocessing and feature engineering
- Model training and prediction
- Simple and responsive design
